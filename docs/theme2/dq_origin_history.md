# D＋Q：谷・山の起点の追加捕捉

初期情報からD＋Q高さ予測を一度だけ作り、固定した予測領域がCPFEMの起点をどれだけ捕捉するか追跡する。評価はstate02〜12に固定し、state13は使わない。欠落stateや節点範囲の不一致を明示し、自動で期間を短縮したり起点0として補ったりしない。

## 計算と集計

設定はm=0.05、指定相当ひずみ0.00901、ばらつき保持率0.75、表面伝達結合0、Q拘束1。予測の局所低さRMSの0.5倍を超える粒を固定候補とする。山は高さ符号を反転して同じ処理を適用し、出力座標を元の高さへ戻す。後続CPFEMから予測粒・閾値を変更しない。

実測起点は[共通の検出定義](../theme1/surface_valley_origins.md)を使用する。

- state02は初期の全起点を数える。
- 後続stateは過去の全観測起点から初期代表粒径の0.5倍より離れた起点を追加する。既存谷上の新規局所最深部と新しい谷の起点を含む。
- 支持粒の少なくとも1つが固定予測粒なら捕捉。粒界上でも重複計上しない。
- 消失した起点を累計から除かず、初出時の捕捉判定を保持する。
- 累積捕捉率は捕捉起点累計／起点総数累計。state別割合の平均ではない。分母0はNaN。

同じ材料座標で比較するが、検出スケール・位置許容幅・出力間隔に依存する新規性であり、物理的核生成の直接証明ではない。

## 表示と出力

谷・山の累積／追加起点の積み上げ棒と累積捕捉率を横並びに表示する。谷は青系・丸、山は赤系・三角・破線。横軸は各rho・seedの `eps_equivalent.csv` の `eps_eq`。先頭データ行をstate01とし、ひずみは表示と検証の座標にだけ使う。

高さマップは谷の予測・state02〜12を1行4枚で全て表示し、その後に山を同様に表示する。谷底線は水色実線、谷起点は星、稜線は橙破線、山起点は三角。新規捕捉・新規未捕捉・既存起点を区別する。

予測図への参照線・起点の転写は節点IDで厳密対応する。線はstate02参照、起点は各stateの初出イベントのみを予測座標へ写す。実測x/yの流用や最近傍探索をせず、予測高さから独立抽出した線であるとは主張しない。

全ケース集計は谷・山ともstate02の初期捕捉率・予測面積率・面積当たり捕捉効率を使う。個別ケースの後続追跡とは別集計であり、終了stateに依存しない。散布図はtexture別・seed別、横軸sd、色と記号rho。起点0のケースは点を描かず表に残す。

PNG、ケース別CSV ZIP、初期集計CSVを保存する。ZIPには谷・山別のcounts/origins/lines/flags/metrics、予測座標、節点IDでの転写座標、方法を収録する。キャッシュは入力ファイルの更新情報と方式バージョンで管理する。

実装：`src/theme2/dq_origins.py`、`src/dashboard/dq_origins.py`。5モデルのstate02比較は[state02評価](valley_onset_state02.md)を参照。
