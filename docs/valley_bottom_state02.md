# state02：谷底線を含む粒を、予測が周囲より低いと捉えるか

現在の主評価。旧「全体平面から粒重心距離RMSを超える谷粒」の評価結果と混ぜない。初期5条件の予測式は変更せず、参照ラベルと予測の検出規則を変更した。

③のRD・TD・せん断はQを通じて使用。④⑤は明示的なD・粒界重みを使わず、共有節点と3D平衡を通じた相互作用を含む。初期方位・指定負荷・初期メッシュという共通入力と表示写像は表から省略。properties.csvも保存する。旧6条件の結果は並べ替えるだけでは新5条件の結果にならず、特にD＋Qの再計算が必要。

## 参照：局所的な谷底線と、それを含む粒

対応する初期材料座標の規則格子へstate02の高さを配置し、全体の傾斜を除く。欠損格子は補間せずエラーにする。0.75格子のGaussian平滑で格子ノイズを抑える。周囲の基準高さは初期可視粒の代表直径の半分をσとするGaussian平均。

周辺基準より低く、最大正曲率の方向で両側より低い箇所を候補とする。局所低さの下限はそのRMSの1%と数値丸め幅の大きい方。深い谷だけを選ぶRMS1倍・固定下位割合は使わない。候補を高さマップの青色域（z < c_low + 0.4(c_high−c_low)、c_low/c_highは表示と同じ節点高さの2/98百分位）に限定する。これは高さ範囲の下側40%であり、下位40%の節点や粒を選ぶ意味ではない。白付近・赤側の局所的な窪みは除外する。線分の両端がこの域内にあること、対角線は通過セルの他の頂点も域内にあることを要求する。候補を細線化し、隣接する点を線分として保存する。孤立点は対象外。外周1格子と不完全な面は除く。

各線分の両端を含む実際の上面要素を使って粒へ割り当てる。共有粒界に線分が載る場合は両側の粒へ割り当て、頂点への点接触だけでは割り当てない。粒内／粒界に沿う線長の合計が0.5格子幅以上の粒を参照対象とする。線の座標はstate02の現在xyz、位置対応用の初期材料座標も保存。粒界上では粒別線長に二重計上があるが、全体の線被覆率は線分IDを一度だけ数える。

この谷底線は格子解像度・平滑化・局所基準幅に依存する操作的定義。厳密な連続曲面の谷線や時間的初発を同定するものではない。実測高さ図に緑線を表示し、妥当性を確認できるようにする。

## 予測：隣接粒より低い粒

各場で粒表面の現在面積重心を計算。可視上面で辺を共有する隣接粒を求め、初期共有辺長／現在の粒重心面内距離を重みとする。3粒以上で非共線なら隣接粒の重心高さに重み付き局所平面を当て、対象粒重心がその平面より下にある量を算出。近傍が不足・共線の場合は全体傾斜を除いた距離の重み付き近傍平均との差へ切り替える。隣接粒がない粒は除外し件数を記録する。

低さが、その予測自身の局所低さRMSの0.5倍と数値幅の大きい方を超えれば低い粒。以前の1%はわずかな低さまで拾っていたため、既定値を厳格化した。UIの「予測谷の厳しさ」で倍率を変更でき、倍率が大きいほど対象を絞る。実測を使って予測側閾値を最適化しない。感度表の0.5倍・1倍・2倍は指定倍率に対する倍率で、既定では実効0.25・0.5・1.0 RMSに相当する。実測側の青色域・谷底線抽出は変更しない。

## 評価と保存

粒IDのPrecision・Recall・F1・IoUを計算。FPは「参照の谷底線を含まない候補粒」で、実際には谷の斜面にある可能性もある。新規捕捉・新規見逃しなど因子別変化を保存。補助のbottom_line_coverageは、予測が低いと判定した粒のいずれかに含まれる参照線分の総長／参照線分総長。共有粒界の片側が予測されればその線分を覆うとみなす。孤立点・外周除去後に残った線だけが分母。

ZIP・CLIにbottom_lines、bottom_line_support、reference_bottom_grains、local_lownessを追加。生高さ・重心・平面も診断用に残すが、全体平面のRMSで正誤を決めない。旧評価のファイルは上書きせず、新CLI既定出力はdatabase/theme1/valley_strict_blue_bottom_state02_five_models、箱ひげ図はoutput/reports/valley_strict_blue_bottom_state02_five_models。

既存予測を再利用して全ケースを再評価する場合：

```
.venv/bin/python -m tools.theme1.plot_onset_boxplots --reuse-predictions output/reports/valley_onset_state02_boxplots/case_data
```

5条件版の設定バージョン・初期入力のmtime・共通条件が一致する場合だけ予測座標を再利用し、参照を読む前に全5条件を読み込む。合わなければ初期情報から再計算する。旧箱ひげ図は新方式の結果ではない。
