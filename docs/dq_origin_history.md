# D＋Q：起点の追加捕捉

比較方法に独立ページを追加。rho・seed・texture・sdで1ケースを選ぶ。評価終了stateまでの全stateを使い、予測は初期組織から一度だけ計算する。

## 計算と集計

既存D＋Qと同じ設定（m=0.05、指定相当ひずみ0.00901、ばらつき保持率0.75、表面結合0、Q拘束1）。予測粒は周囲より低い程度が予測自身のRMSの0.5倍を超える粒。後続CPFEMで予測粒や閾値を変更しない。3D平衡モデルやTaylor factor差の和集合は使用しない。

- state02：初期に検出した全起点を計数。
- state03以降：過去の全観測起点から初期代表粒径の0.5倍より離れた局所起点のみ追加計数。既存谷上の新規局所最深部と、独立した新しい谷での起点の両方を含む。
- 捕捉：起点の支持粒の少なくとも1つが固定されたD＋Q予測粒に含まれる。粒界上で両側に支持されても1起点を1回だけ数える。
- 積み上げ棒：下側＝捕捉数、上側＝未捕捉数。後続stateでは各stateの新規起点数を表す。
- 黒い折れ線（右軸）：state02からの捕捉起点累計／起点総数累計。各stateの割合を平均しない。
- CSVにはstate03以降だけの累積数・累積捕捉率も保存する。

起点がないstateも棒の位置を残す。累積分母0は未定義（NaN）。同一節点範囲かつstate02から終了stateまで連続した観測があることを要求する。欠落stateを起点0として扱わない。

同一材料座標で位置を比較するが、抽出規則と位置許容幅による「検出上の新規性」であり、物理的核生成の直接証明ではない。

## 表示と出力

予測高さマップと全stateの実測高さを1行4枚で表示。緑線＝実測谷底線、星＝そのstateの集計対象起点（青＝捕捉、橙＝未捕捉）、灰丸＝既存起点。各場で独立した2–98%色域。

最終捕捉率は、全rho・texture・sd・seedを同じ終了stateまで集計するボタンで表示。textureを列、seedを行とするパネルで、横軸sd、縦軸最終累積捕捉率、色と記号rho。sdは実際の数値位置に置く。欠損ケースは除外理由を表示し、起点総数0のケースは点を描かず表に残す。

PNG、ケース別CSV ZIP（集計・起点・谷底線・予測粒・予測高さ・方法）、最終捕捉率CSVを保存可能。ケース計算は入力ファイルの更新時刻・サイズと方式バージョンをキーにキャッシュする。

2026-10-28：棒グラフの標準表示を累積起点数へ変更。消失した起点も初出時の捕捉判定を保持し、新規起点だけを追加する。元のstate別追加数にも切り替え可能。捕捉率は従来から同じ累積定義であり、消失による減算は行っていない。未捕捉の新規起点が追加されると、捕捉数が不変でも率は下がりうる。CSVにcumulative_missedを追加した。

起点捕捉グラフの横軸は各rho・seedの`eps_equivalent.csv`の`eps_eq`とする。CSVの先頭データ行をstate01として対応させ、棒・折れ線・注記を実ひずみ値の位置に配置する。棒幅は隣接ひずみ間隔から定め、不等間隔の最終出力にも対応する。集計CSVにstateとeps_eqを併記し、方法JSONにひずみファイルを記録する。ひずみは表示と検証の座標にのみ使用し、初期予測へフィードバックしない。

D＋Q予測マップへstate02実測谷底線と全stateの新規起点を重ねる。線端点のnode_a/node_bと起点代表node_idを予測座標のnode_idに厳密対応させ、予測側x/y/zへ写す。実測x/yの流用、最近傍探索、粒重心への置換は行わない。起点はis_eventのみで、発生state別の色と凡例を付ける。緑線は実測から対応付けた参照線であり、予測場から独立抽出した線ではない。重ね合わせPNGと、投影前後の座標を含むprojected_state02_lines.csv・projected_origin_events.csvを保存できる。

集計散布図の指標を初期捕捉率へ変更（2026-10-28）。初期捕捉率＝state02の捕捉起点数／state02の起点総数。全ケース集計ではstate02のみを読み、個別ケースの評価終了stateには依存しない。texture別・seed別、横軸sd・色と記号rhoの配置を維持する。CSVはinitial_origin_count、initial_captured、initial_missed、initial_capture_rate、対応eps_eqを保存する。各ケースの累積捕捉率推移は引き続き表示する。

## 2026-10-29：谷・山の対称追跡とstate12固定

D＋Qの同じ予測高さ場で、谷と山をそれぞれstate02〜12まで追跡する。山は高さ符号を反転して谷と同じ検出・新規判定・累積規則を適用し、出力座標は元の高さへ戻す。初期予測領域は谷・山それぞれで固定。消失した起点を累計から除かない。

UIは両者の累積／追加起点の積み上げ棒＋累積捕捉率の折れ線を横並びに表示。谷は青系・丸の折れ線、山は赤系・三角・破線。横軸と初出凡例は相当塑性ひずみ。

高さマップには両者を同時に表示する（1行4枚）。谷底線＝水色実線、谷起点＝星、稜線＝橙破線、山起点＝三角。実測図の濃色は新規捕捉、薄色は新規未捕捉、白抜きは既存起点。予測図にはstate02実測の両線と各state初出の両起点を節点IDで転写し、初出ひずみを青系／赤系で符号化する。これらは予測高さから独立抽出した線ではない。

旧「初期予測粒の内訳：起点・谷・FP」図、山だけの展開欄、終了stateの選択を削除。state02〜12の欠損は明示し、自動で短縮しない。state13は解析・描画しない。

全ケースの初期集計・散布図はfeature=valley/peakを両方出力。全ケース初期集計はstate02のみを使用する従来仕様を維持。ケースZIPは両者のcounts/origins/lines/flags/metrics/転写座標を別フォルダに収録する。

### 表示の分離

視認性のため谷・山は別の高さマップに変更。同じ予測／stateの4列を上段＝谷、下段＝山で揃える。各図は当該特徴だけを描画しPNGも個別に出力。累積グラフ・集計・state12固定・予測値は変更しない。

表示順を再整理：谷の予測・state02〜12を1行4枚で全て表示し、その後に山の予測・state02〜12を同様にまとめて表示する。谷と山の行を交互に挿入しない。
