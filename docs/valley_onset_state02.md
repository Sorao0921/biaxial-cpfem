# 初期組織から谷形成起点を説明する：state02比較

目的は最終高さ場の再現ではなく、変形初期の谷となる粒の位置を説明する物理情報の切り分け。主評価はCPFEM state02。谷の拡大・接続・合体、state13の振幅予測は今回の対象外。

## 初期情報だけによる6条件

1. 自粒NDのみ：自身のKをND収縮傾向へ変換。周囲との差D・Q・表面グラフ伝達は使わない。
2. 周囲とのND差：同じ高さ換算で駆動をD=K−近傍重み平均Kへ変更。表面伝達結合なし。
3. ND差＋結合：2と同じDに表面伝達結合λ=1を追加。旧KベースAに対応。
4. D＋Q：3と同じD・λに、Qによる局所復元拘束γ=1を追加。旧Bに対応。
5. 3D対角のみ：同じ初期Sachs応答・緩和を計算した後、固有ひずみxy・xz・yzをゼロにして平衡を解く。
6. 3D全成分：5と同じ境界・弾性・初期応答で全6成分を使用。旧Cに対応。

1→2、2→3、3→4、5→6を対応づけて比較する。4→6など縮約式から3Dへ移る比較では複数の仕組みが変わるため、単一因子の効果とは呼ばない。自粒NDでも負荷の応力比・共通倍率は全粒の初期体積平均で決める。表面共有節点への同じ面積加重写像は全縮約条件で使用する。

## 共通条件と負荷量

m=.05、事前指定相当ひずみ=.01、ばらつき保持率=.75、ν=.3が既定値。応力比βは全粒初期体積平均のTD/RD比が指定ρになるよう逆算する。state02の実ひずみ・応力・すべり量や後続stateを予測に使わない。.01はstate02の実ひずみであるとの主張ではない。

旧保持率.75は探索的設定を継承。新たなCPFEMへの係数最適化はしないが、未見結果だけで設定された物性と主張しない。

応答は初期状態で凍結される。一定形状・一定作用素の下では変位の負荷量比例が基本となるが、現在面積での重心計算・表示形状・閾値分類まで厳密に不変とは主張しない。負荷量を変えて位置の安定性を確認できる。実際の高さ場の単調成長・線形成長を予測モデルの成立前提にはしない。

## 谷の主評価

各場に独立な最小二乗平面を当て、露出粒表面の現在面積重心から平面への符号付き法線距離dを計算。各場独自のδ=√平均(d²)に対しd<−δを谷とする。同じ粒IDの一致をPrecision・Recall・F1・IoUで評価。閾値.5倍・1倍・2倍も併記。谷粒がない場合のPrecisionは未定義のまま。無作為比較・無作為基準の倍率は新しい画面・CSVに含めない。

因子追加ごとにnew_hit（新規捕捉）、lost_hit（新規見逃し）、new_false_alarm（新規誤検出）、removed_false_alarm（解消した誤検出）を粒IDごとに保存する。これは各モデル自身の自動閾値で分類された結果の比較であり、因子を加えた粒の高さ変化の因果同定ではない。

state02は操作的に選んだ起点。真の初発時刻を同定したものではなく、初期表面が既に荒い場合は初期低部と新規形成を区別する追加確認が必要。非常に小さい凹凸は出力精度・初期形状との比較を要する。画面にはstate02の粒距離RMSを表示する。値を自動で増幅・クリップしない。

## 後続stateの補助確認

任意表示でstate02以降の参照高さを読み、state02の谷粒が後続stateでも谷として検出される割合を共通可視粒だけで計算。予測入力や条件設定へ戻さない。独立な閾値による残存率であり、単調性や拡大・合体の予測精度を証明するものではない。

## 使用法

UIの「谷形成起点の因子比較（state02）」を使用。全240条件から選択できる。谷の一致マップ／生高さを切り替え、6条件と参照を横1行に表示。生高さは独立2–98%表示で、負荷量を実測に合わせていないため振幅一致を主評価にしない。

単一条件の保存例：

```
.venv/bin/python -m tools.theme1.compare_valley_onset --rho -0.5 --seed 1 --texture brass --sd 2
```

フィルタを指定しなければ利用可能なstate02全条件を計算する。予測座標・条件は参照読込前に保存。出力はdatabase/theme1/valley_onset_state02以下で、旧state13の結果は上書きしない。ZIPには初期指標・粒界情報・予測座標・初期テンソル・谷判定・重心・平面・閾値・因子別の粒ID変化を含む。CLIには全変位も保存する。

## 全ケースの予測・箱ひげ図出力

```
.venv/bin/python -m tools.theme1.plot_onset_boxplots
```

state02の全ケースで6条件を計算し、`output/reports/valley_onset_state02_boxplots/`へ保存する。`individual_models/`にモデル別・ひずみ比別の18図、`all_boxplots.pdf`に個別図をまとめる。各パネル内にPrecision・Recall・F1を並べる。3つのoverview図は6条件を2行3列で表示。

主集計は粒・谷・自動閾値1倍のみ。全閾値CSVは節点・山・閾値感度も含むが、箱ひげの標本には混ぜない。モデル別のケース精度・箱統計・全ケースCSV・対象一覧・条件別件数を保存し、未定義を0に置換しない。全ケースの予測座標・条件・重心・閾値・因子別変化はcase_data以下に保存する。ZIPは図と集計CSVを収録し、大容量のcase_dataは除く。`--plots-only`で計算済みCSVから図を再生成できる。
