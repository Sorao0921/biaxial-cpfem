# 初期方位からの応力基準ND収縮指標χ・K

## 入力・仮定

- 初期方位CSV（Bunge角、radian）と初期3Dメッシュだけを入力する。
- σ = σ0 diag(1, β, 0)。βはTD/RDの応力比で、面内せん断を無視した平面応力近似。
- 等応力、FCC12すべり系、全粒・全系に共通の一定CRSS、共通mと基準速度。硬化と方位更新は行わない。
- 変形中のすべり・方位・局所応力やstate13高さは指標計算に使わない。
- βと、ケース選択のひずみ比rhoは独立。βから得られる平均ひずみ比をrhoへ一致させる逆解析は今回行わない。パラメータ感度として比較する。

## 計算

初期方位から試料座標の系方向s・面法線nを計算する。

```
S_gα = sym(s_gα ⊗ n_gα)
tau_hat_gα = S_gα,xx + β S_gα,yy
a_gα = sign(tau_hat_gα) |tau_hat_gα|^(1/m)
A_g = sumα a_gα S_gα
```

元の速度則 `gamma_dot=gamma_dot0*sign(tau)*|tau/g0|^(1/m)` の共通倍率 `C=gamma_dot0*(σ0/g0)^(1/m)` は、以下の規格化で消える。異なるCRSSがある場合、その比は消えない。しきい値付きの別構成則にも、そのまま適用しない。

```
eq(A) = sqrt((2/3) A:A)
χ_g = -A_g,zz / eq(A_g)
A_bar = sum_g V_g A_g / sum_g V_g
K_g = -A_g,zz / eq(A_bar)
```

正はND収縮、負はND伸長。χは粒自身の変形に占めるND方向の配分、Kは全粒共通の尺度で規格化したND変形量であり、粒間の活動量差を保つ。`eq(A_bar)` は `average(eq(A_g))` と異なる。χは数学的には−1〜1に収まるが、その範囲へ表示を固定せずケースの値で描画する。Kは同じ範囲に制限されない。

Vは初期メッシュの8節点六面体を2×2×2 Gauss積分して計算する。表示される表面粒や表示cropだけでなく、初期メッシュ内の全粒・全要素を含める。節点順序はLS-DYNAの通常の8節点brick順序を前提とし、負のJacobianや欠損方位はエラーにする。

## 数値安定性

mが小さいとべき乗値が極端になるため、各粒の最大分解せん断応力で局所活動の形を計算し、粒間振幅を別に保持する。Kを求める際は振幅を必ず戻し、全体共通倍率だけを取り除く。χに対する粒別正規化をKへ流用しない。計算上の共通スケールは物理的な絶対すべり速度ではない。

## 画面

「初期指標と表面高さ（state13）」に次を1段3枚の2段で表示する。上段はM・P_abs・P−、下段はχ・K・state13高さ。

1. 初期Taylor M
2. 初期Taylor P_abs
3. 初期Taylor P−
4. 初期応力基準χ
5. 初期応力基準K
6. state13の実際の表面高さz

初期5枚はstate1の座標・表示範囲を使う。state13を初期5枚の座標へ代用しない。高さは正規化・基準面除去をせず、表示節点の高さの2〜98百分位を色範囲に使う（描画単位へのHEIGHT_SCALE変換のみ）。範囲外の値は削除せず端色で表示する。βの既定0、mの既定0.05は探索用であり、材料同定値ではない。UIのm範囲は0.005〜1、βは−2〜2。各PNGにはstateを、χ・Kにはβ・mも記録する。β・mはTaylor指標を変更しない。

Mは低値が黄色、P・χ・Kは高値が黄色。これは抵抗／寄与の向きの可視化であり、黄色を谷や山の確定予測として解釈しない。

## 全指標の外れ値への対応

表示中の粒の元の値について、2百分位と98百分位を色範囲にする。1粒1票で、要素数・面積による重みは掛けない。端の値をカラーバーの外に飽和表示するだけであり、計算値・順位・初期入力は変更しない。指標の数値が大きいことを理由にデータを削除しない。全値一定など分位点が一致する場合は、微小な幅を与えて表示する。M・P_abs・P−・χ・Kすべてに同じルールを適用する。高さには別途、表示節点を等重みとした2〜98百分位を適用する。分位点は実測高さへの一致を見て調整しない。

## 解釈の限界

これは初期方位固定の変形傾向指標であり、高さ場を時間積分した予測ではない。粒界変形適合・局所応力再分配・自由表面の変位境界値問題を解いていない。β・mを変えて最も実測と合うものだけを採用する場合は、事前予測と事後選択を区別する。

## 面内成分

K_RD=Axx/eq(mean A)、K_TD=Ayy/eq(mean A)。正値が伸長。既存のK_ND=-Azz/eq(mean A)とK_RD+K_TD=K_NDを満たし、三成分を独立な収縮ひずみとして重ねてはならない。
