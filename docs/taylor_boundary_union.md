# 初期Taylor factor差の粒界候補と既存5条件の和集合

高さ予測・実測の起点検出を変えず、初期Taylor factor差が大きい表面共有粒界を別の候補チャネルとして追加する。各粒の初期Euler角と指定ひずみ比rhoから、等CRSS FCC Taylor factor Mを求める。変形中のMやCPFEM応力は使わない。

粒界i-jの指標はabs(M_i-M_j)。初期表面全体の共有辺長で重み付けした差のRMSを基準とし、既定は1倍より大きい粒界を採択。閾値は実測起点やモデル順位へ合わせて最適化しない。UIでRMS倍率を変更可能。

候補は共有辺そのもの。両側の粒全体を候補にしない。実測起点の節点IDから初期材料座標を求め、候補辺への最短距離が初期の最小共有辺長の0.5倍以内なら粒界チャネルによる捕捉とする。粒内で離れた起点には加点しない。三重点など複数粒界に近い起点は帰属候補を全て保存し、曖昧な起点数を報告。粒界側の統計単位は可視上面で同じ二粒が共有する粒界ペア。

各モデルの起点捕捉OR粒界チャネルの起点捕捉で和集合を作る。origin_id単位で一度だけ数える。元モデル、粒界単独、和集合の捕捉数・捕捉率、新規捕捉数、両チャネル共通の捕捉数を保存。

粒界候補の的中率は、state02の実測起点を含む候補粒界ペア数／候補粒界ペア数。起点を含まない候補数・候補粒界長・可視全粒界長に占める割合も併記する。未対応候補が後で起点を形成する可能性は、このstate02評価だけでは確認も否定もできない。粒と粒界で単位が異なるため、和集合のPrecision/F1は作らない。

UIの紫線が候補粒界。上段の検出図は初期材料座標、下段は各高さ図の表示座標に同じ節点IDで描画する。従来の粒のTP/FP塗り分けは元モデルのままで、紫線が追加チャネル。表とCSVの和集合結果は両方を含む。

保存ファイル：
- taylor_factors.csv：初期M
- taylor_boundary_segments.csv：可視共有辺・Delta M・採択
- taylor_boundaries.csv：粒界ペア別の長さ・候補判定・実測起点の有無
- taylor_origin_boundary.csv：起点と近接粒界の対応・距離・三重点フラグ
- taylor_boundary_metrics.csv：粒界単独の捕捉と候補規模
- union_metrics.csv：各モデルとの和集合
- union_origin_flags.csv：起点ごとのmodel_only / boundary_only / both / miss

ZIPとCLI・全ケース集計に対応。初期入力と条件が一致する過去の高さ予測は再利用可能だが、和集合評価は再計算する必要がある。追加で拾えたことだけで因果関係が証明されたとは扱わない。
