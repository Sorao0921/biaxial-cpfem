# Theme 1 要件定義 v0.1

## 1. 研究上の問い

### 主たる問い

1. 表面粗さは、どのグラフ空間スケールで発生するか。
2. 粗さを支配するのは次のどれか。

   - 粒内の塑性変形不均一
   - 隣接粒間の塑性変形不適合
   - 複数粒にまたがる長波長の協調変形
   - 試験片全体の巨視的な変形

3. 支配スケールは以下によって変化するか。

   - 二軸応力比 `rho`
   - texture
   - 方位分散 `sd`
   - seed、すなわち粒配置
   - 変形段階 `state`

### 副次的な問い

- GOS・粒回転・累積せん断ひずみのうち、粗さと同じ空間モードを持つ量はどれか。
- 総累積せん断ひずみより、すべり系別の活動差や隣接粒間差の方が粗さをよく説明するか。
- 粒配置が異なっても共通する粗面化則を構築できるか。
- textureごとに異なる粗面化機構が存在するか。

## 2. 分析対象

### ケース

1ケースを次で定義します。

\[
c=(\rho,\ seed,\ texture,\ sd,\ state)
\]

現在のデータベースには、

- Theme 1解析可能ケース：1,680
- 粒配置：4 seed
- `rho`：−0.5、0、1
- 複数のtexture、sd、state

が存在するため、初期解析には十分なケース数があります。

ただし、実質的に独立な粒配置は4つしかありません。要素数やケース数が多くても、汎化性能を評価するときの独立サンプルはseed数に強く制限される点には注意が必要です。

### 空間単位

解析では3つの空間単位を区別します。

- 表面要素：局所的な高さとせん断ひずみ
- 表面結晶粒：グラフのノード
- 粒界：グラフのエッジ

GNNやグラフFourier解析の基本単位は「表面結晶粒」とします。一方、粒内不均一を評価するため、要素情報も失わず保持します。

## 3. 表面粒グラフの定義

各seedに対して、変形前の空間モデルから一つの固定グラフを作ります。

\[
G_s=(V_s,E_s)
\]

### ノード

表面に露出している結晶粒をノードとします。

ノードIDは `part_id` とします。

各ノードには次を付与します。

- `part_id`
- 表面積
- 表面重心座標
- 表面要素数
- 粒径相当量
- 初期結晶方位
- texture、sd
- 各stateのGOS
- 各stateの粒回転
- 各stateの粒平均累積せん断ひずみ
- 各stateの粒平均面外変位
- 粒内変動量

### エッジ

表面上で異なる `part_id` の要素が辺を共有するとき、2粒を隣接と定義します。

単に節点を1個共有するだけの粒は隣接としない方がよいです。角で接するだけの粒まで含めると、力学的な粒界接触を過大評価するためです。

エッジには次を付与します。

- 共有粒界長
- 粒重心間距離
- 粒界の面内方向
- 初期方位差角
- GOS差
- 粒回転差
- 累積せん断ひずみ差
- すべり系別せん断ひずみ差
- 将来的にはSchmid factor差、\(m'\)

### エッジ重み

初期版では次の2種類を比較します。

\[
w_{ij}^{(1)}=1
\]

\[
w_{ij}^{(2)}
=
\frac{\text{共有粒界長}_{ij}}
{\|\boldsymbol{x}_i-\boldsymbol{x}_j\|}
\]

第一式は純粋な隣接関係、第二式は粒界長と粒間距離を考慮した力学的にやや自然な重みです。

どちらを採用するかは、結果がエッジ重みの定義に過度に依存しないことを確認して決めます。

## 4. 各物理場の定義

## 面外変位・高さ

現状の基準面除去後高さについて、絶対値を取る前の符号付き残差を使います。

\[
h_e=z_e-\hat z(x_e,y_e)
\]

ここで \(\hat z\) はケースごとの最小二乗基準面です。

粒平均高さは

\[
\bar h_g
=
\frac{\sum_{e\in g}A_eh_e}
{\sum_{e\in g}A_e}
\]

とします。要素面積が一定でも、将来のメッシュ変更に耐えられるよう面積重みを基本とします。

粗さの発達を調べる場合は、

\[
\Delta h_{g,t}
=
\bar h_{g,t}-\bar h_{g,t-1}
\]

も計算します。

初期版では、次の両方を解析します。

- 各stateの高さ場 \(h_t\)
- state間の高さ増分 \(\Delta h_t\)

高さ増分の方が「その変形段階で粗さを何が生んだか」を説明しやすい一方、差分によって数値ノイズが増える可能性があります。

## 累積せん断ひずみ

現在のデータには総量だけでなく12すべり系別の累積せん断ひずみが含まれています。これは重要なので保持します。

粒平均：

\[
\bar\gamma_g
=
\frac{\sum_{e\in g}V_e\gamma_e}
{\sum_{e\in g}V_e}
\]

粒内不均一：

\[
H_g^\gamma
=
\sqrt{
\frac{\sum_{e\in g}V_e
(\gamma_e-\bar\gamma_g)^2}
{\sum_{e\in g}V_e}
}
\]

すべり集中度：

\[
C_g^\gamma
=
\frac{
\max_\alpha \bar\gamma_g^\alpha
}{
\sum_\alpha \bar\gamma_g^\alpha+\epsilon
}
\]

すべり系の有効数：

\[
N_{\mathrm{eff},g}
=
\frac{1}{
\sum_\alpha p_{g,\alpha}^2
},
\qquad
p_{g,\alpha}
=
\frac{\bar\gamma_g^\alpha}
{\sum_\beta\bar\gamma_g^\beta+\epsilon}
\]

これにより、

- 総すべり量が大きい
- 少数すべり系に集中している
- 多数のすべり系に分散している

を区別できます。

## 粒回転・GOS

粒回転は粒平均信号としてグラフ分解します。

GOSは、単なる説明変数というより、

> 粒内方位不均一の代理指標

として位置付けます。

したがって、

- 累積せん断ひずみの粒内標準偏差
- GOS
- 粒回転

をすべて同じ「寄与変数」と扱うのではなく、異なる機構の指標として整理します。

## 5. 粗さの三成分分解

ここがこの研究の中心です。

表面要素の高さを、次のように分けます。

\[
h_e
=
h_e^{\mathrm{intra}}
+h_g^{\mathrm{inter}}
\]

### 粒内成分

\[
h_e^{\mathrm{intra}}
=
h_e-\bar h_{g(e)}
\]

同一粒内での局所的な凹凸です。

粒ごとの粒内粗さは、

\[
R_{q,g}^{\mathrm{intra}}
=
\sqrt{
\frac{1}{N_g}
\sum_{e\in g}
(h_e-\bar h_g)^2
}
\]

とします。

### 粒間成分

粒平均高さ場

\[
\boldsymbol h_G
=
(\bar h_1,\bar h_2,\ldots,\bar h_{N_G})
\]

をグラフ上の信号として扱います。

この信号にグラフFourier変換を適用し、

\[
\boldsymbol h_G
=
\sum_k \hat h_k\boldsymbol\phi_k
\]

と分解します。

### 長波長成分と粒間不適合成分

正規化グラフLaplacian

\[
L_{\mathrm{norm}}
=
I-D^{-1/2}AD^{-1/2}
\]

を固有値分解します。

\[
L_{\mathrm{norm}}\boldsymbol\phi_k
=
\lambda_k\boldsymbol\phi_k
\]

- 小さい \(\lambda_k\)：隣接粒が同じ方向に動く長波長・協調モード
- 大きい \(\lambda_k\)：隣接粒で高さが急変する短波長・不適合モード

と解釈します。

ただし、最初から「高周波＝物理的不適合」と断定せず、

> 高グラフ周波数は隣接粒間差を表し、それが塑性変形不適合と対応するかを検証する

という立場にします。

最終的な三成分は、

\[
h
=
h^{\mathrm{intra}}
+h^{\mathrm{inter,high}}
+h^{\mathrm{long}}
\]

と定義します。

- \(h^{\mathrm{intra}}\)：粒内凹凸
- \(h^{\mathrm{inter,high}}\)：粒間で急変する成分
- \(h^{\mathrm{long}}\)：複数粒にまたがる滑らかな成分

## 6. 周波数帯の決め方

低・中・高周波の境界を恣意的に決めないことが重要です。

初期版では、固有値の個数ではなく累積エネルギーと実効空間範囲を使います。

候補は、

- low：おおむね3粒以上にまたがるモード
- middle：1～3粒程度の変化
- high：隣接粒間で符号や大きさが急変するモード

です。

実装上は複数のカットオフを試し、

- seed間で結論が安定するか
- texture間比較がカットオフに依存しないか
- 粗さの再構成誤差が十分小さいか

を確認します。

最終的なカットオフは、結果をよく見せる値ではなく、事前に定義したルールで選びます。

## 7. 最初に計算する主要指標

ケース \(c\)、場 \(x\)、周波数帯 \(b\) について、

\[
E_{x,c,b}
=
\sum_{k\in b}\hat x_{c,k}^2
\]

を周波数帯別エネルギーとします。

高さについては、

\[
P_{h,c,b}
=
\frac{E_{h,c,b}}
{\sum_b E_{h,c,b}}
\]

を計算します。

これにより、「そのケースの粗さの何%が長波長／粒間／粒内にあるか」を表現できます。

主要な応答指標は次です。

- 粒内粗さエネルギー
- 低グラフ周波数の高さエネルギー
- 中グラフ周波数の高さエネルギー
- 高グラフ周波数の高さエネルギー
- 各帯域の粗さエネルギー比率
- state間の各帯域エネルギー増分

説明指標は次です。

- せん断ひずみの帯域別エネルギー
- 粒回転の帯域別エネルギー
- GOS
- 粒内せん断ひずみ不均一
- すべり集中度
- 有効すべり系数
- 隣接粒間差

## 8. 疎な階層モデル

最初の統計モデルはケースレベルにします。

\[
\log E_{h,c,b}
=
\alpha_b
+\beta_{\gamma,b}\log E_{\gamma,c,b}
+\beta_{r,b}\log E_{\mathrm{rotation},c,b}
+\beta_{\mathrm{GOS},b}\log E_{\mathrm{GOS},c,b}
+u_{\mathrm{texture},b}
+u_{\mathrm{seed},b}
+f_b(state)
+\epsilon_{c,b}
\]

目的は個々の粒の高さを完全に予測することではなく、

> 各物理場のどの空間帯域が、粗さの同じ帯域の成長を説明するか

を推定することです。

### 階層構造

最低限、次を考慮します。

- seed：ランダム効果
- texture：固定効果または部分プーリング
- sd：texture内効果
- rho：固定効果
- state：時系列または滑らかな効果
- 同一ケース系列内の自己相関

### 疎性

候補変数が増えるため、horseshoe priorまたはgroup LASSOを使います。

すべり系別12変数は個別に無制限に投入せず、

- すべり総量
- すべり集中度
- 有効すべり系数
- 物理的に対応するすべり系グループ

としてまとめるのが初期版として安全です。

## 9. 仮説

解析前に、少なくとも次を仮説として固定します。

### H1

表面粗さの主要成分は、粒径程度の空間スケールに対応する中～高グラフ周波数に現れる。

### H2

高さの中～高周波エネルギーは、せん断ひずみ総量よりも、隣接粒間のせん断ひずみ差によってよく説明される。

### H3

GOSは粒内粗さ成分と、粒回転差は粒間粗さ成分と強く対応する。

### H4

低グラフ周波数の高さ成分は、局所的な結晶塑性量よりrhoや境界条件の影響を強く受ける。

### H5

粗面化の支配帯域はtextureおよび方位分散sdによって変化する。

## 10. 検証方法

ランダムな要素分割は使用しません。

### 必須の検証

- leave-one-seed-out
- leave-one-texture-out
- 後半stateをテストとする時間外挿
- rho別の再推定
- エッジ重み定義の感度解析
- 周波数カットオフの感度解析
- 粒面積重みの有無の比較

### 数値的な受け入れ条件

- グラフに孤立ノードがない、または理由を記録できる
- 表面粒・要素の対応率が99%以上
- グラフFourier逆変換の相対再構成誤差が \(10^{-10}\) 以下
- Parseval型のエネルギー保存誤差が \(10^{-10}\) 以下
- ノード番号の並べ替えで結果が変わらない
- 高さの平面除去後平均が数値誤差範囲で0
- 同一seedでは全ケースで同一グラフが使用される
- 結論が単一の周波数カットオフだけに依存しない

統計的な合格基準は固定の \(R^2\) 値だけにせず、

- 未学習seedに対する性能
- 係数の符号安定性
- 変数を除いたときの予測低下
- bootstrap／事後分布の不確実性

で判断します。

## 11. MVPと発展版

### MVP：現在のデータだけで実施

- 表面粒隣接グラフ
- 符号付き高さ
- 粒内高さ分散
- 総累積せん断ひずみ
- 12すべり系の集中度
- GOS
- 粒回転
- グラフスペクトル分解
- ケースレベル階層モデル

これは追加のUMAT計算なしで実現できます。

### 発展版

追加出力が可能なら、

- 塑性ひずみテンソル
- 面外塑性ひずみ \(D^p_{nn}\)
- 応力テンソル
- 塑性仕事
- すべり速度
- Schmid factor
- 粒界すべり伝達係数 \(m'\)

を加えます。

特に面外塑性ひずみがあれば、高さ変化との物理的接続が大幅に明確になります。ただしMVPの開始条件にはしません。

## 12. 成果物

最終的に必要な成果物は以下です。

1. seedごとの表面粒グラフ
2. 粒・粒界特徴量テーブル
3. グラフ固有値・固有モード
4. 各物理場のグラフスペクトル
5. 粗さの粒内・粒間・長波長分解
6. ケース別帯域エネルギーテーブル
7. 階層モデルの係数・不確実性
8. leave-one-seed-out評価
9. texture・rho・state別の比較図
10. 解析条件と感度分析を含む診断ファイル

実装順としては、まず「1ケース・1seedでグラフ構築と高さの完全再構成ができること」を最初のマイルストーンにするのが安全です。その後、全ケース展開、物理場比較、階層モデルの順に進めます。

この要件定義で特に重要なのは、GNNを最初から学習器として導入していない点です。まずグラフを「物理的な空間座標系」として使い、そこで説明できない非線形な近傍相互作用が残った場合にのみGNNへ進む構成になっています。これなら研究の主張がぶれにくくなります。
