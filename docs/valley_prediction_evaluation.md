# 各高さ場で独立に検出した山・谷の粒一致評価

予測とCPFEMを平面で重ね合わせたり、両者の高さずれを最小化したりする評価ではない。各場自身で山・谷を検出し、検出した結晶粒IDの一致度を比較する。予測値・係数・振幅は変更しない。

## 検出手順

1. 各モデルとCPFEMそれぞれの現在節点座標に、独立に最小二乗平面 `z=a*x+b*y+c` を求める（z残差の通常最小二乗）。
2. 各粒の露出した上面要素を2三角形に分割し、現在の三角形面積で加重した粒表面の面積重心 `(xc,yc,zc)` を求める。これは3D粒全体の体積重心ではない。表示端の粒は可視部分の完全な要素だけを使う。
3. 重心からその場自身の平面への符号付き垂直距離 `d=(zc-a*xc-b*yc-c)/sqrt(1+a²+b²)` を求める。上側が正。
4. 各場の粒重心距離から独立に自動閾値 `δ=sqrt(mean(d²))` を求める。粒は等重み。山は `d>δ`、谷は `d<−δ`、それ以外は中立。ちょうど閾値は中立。平坦場では何も検出しない。
5. 予測で検出された粒IDとCPFEMで検出された粒IDを比較する。

RMSの1倍を事前に統一した検出規則とする。同じ絶対距離や同じ対象割合を強制しない。予測側の平面・重心・閾値の計算にはCPFEM高さを使わない。この評価は各場自身の凹凸規模に対して顕著な粒の位置を調べるもので、絶対振幅の一致を示すものではない。RMSは極端な凹凸の影響を受けるので、0.5倍・1倍・2倍を併記する。

## UIと指標

メインの生高さ4枚はそのまま。評価欄で山／谷を切り替え、検出一致マップを横4枚表示する。緑は一致、橙は誤検出、青は見逃し／参照対象、灰は双方で対象外。初期材料座標に同じ粒IDを表示する。

捕捉率（Recall）、的中率（Precision）、F1、IoU、対象粒数、予測とCPFEMそれぞれの自動閾値を表示する。参照対象ゼロではRecall/F1/IoU/APは未定義。予測対象ゼロではPrecisionは未定義。非対象が多いことだけで高くなる全粒正解率を主指標にしない。

節点領域の補助評価もCSVに保存する。その場合の自動閾値は各場の節点距離RMS。UIの主評価は粒重心のみ。FFTは独立した補助診断で、山・谷の検出には使わない。

## 保存と再実行

ZIPにはmetrics、flags、raw node/grain heights、node/grain distances、planes、centroids（各場の現在面積重心・面積・符号付き距離）、thresholds（各場・評価単位の自動閾値）、method.jsonを保存する。planesのSqは節点距離RMSで、粒の検出閾値はthresholds内のgrain行を参照する。

```
.venv/bin/python -m tools.theme1.evaluate_valleys
```

保存済み4者比較の各条件フォルダに `centroid_detection_evaluation/` を作り、山・谷の粒一致PNGを保存する。集計は `centroid_detection_summary.csv`。`--skip-maps`、`--case`、`--fft` も利用可能。旧順位法・共通絶対距離法の出力は上書きしない。互換用の `--distance-threshold` を明示した場合のみ旧共通距離に切り替わる。UIでは使用しない。

## texture別箱ひげ図

```
.venv/bin/python -m tools.theme1.plot_detection_boxplots
```

state13の全ケースで初期3モデルを計算し、粒重心の自動閾値1倍のPrecision・Recall・F1をtexture別に集計する。ひずみ比と山／谷を分け、K・D/Q・3Dを別パネルにし、各パネル内でPrecision・Recall・F1を色分けした箱ひげと全ケースの点を表示。CSVもモデル別に分け、3指標を同じ表の列にまとめる。箱の標本単位は1ケース（seed・sd）で、粒や閾値倍率を標本数に混ぜない。未定義を0に置換しない。出力は `output/reports/centroid_detection_boxplots/`。PNG・PDF・ケース別CSV・箱の統計CSV・条件別件数を保存し、トップレベルの成果物をZIPにまとめる。ケースキャッシュにより中断後も再開可能。`--plots-only` は集計済み全閾値CSVから図を再生成する。
