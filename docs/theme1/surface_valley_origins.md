# 実測高さ場からの谷・起点検出（2026-10-29）

D＋Qの高さ予測、局所低さ、予測採択閾値は変更しない。実測の起点は、谷底線を前提にせず、初期材料座標の規則格子に戻したCPFEM高さ場から抽出する。

1. 全体の最小二乗平面を除去し、標準偏差0.75格子のGaussianで微小な凹凸を平滑化する。
2. 周囲の基準高さはGaussian（標準偏差：初期代表粒径の半分、最低1.5格子）とする。基準高さからの落ち込みがそのRMSの0.5倍を超える領域を谷領域とする。表示色に依存しない。
3. 8近傍の高さグラフで局所最深部・平坦底を検出する。prominenceは平滑化した傾き除去高さの全幅の5%超。同一近傍の候補は深い順に代表粒径の半分まで抑制する。これは物性定数ではなく検出スケールであり、予測との一致に合わせて調整していない。
4. 最深部の平坦領域が解析範囲端に接する候補はboundary_originsに保存し、内部起点の捕捉率から除外する。検出マップでは灰色×。端点候補に起因する不確かさは残る。
5. 起点を含む表面要素の所属粒を起点支持粒とする。粒界上では複数粒が支持できるが、起点の捕捉は1回だけ数える。
6. 谷領域の節点比率を表面要素ごとに面積積分し、露出粒面積の10%以上なら谷粒。既存の谷底線が正の長さで通る粒も谷粒とする。

予測粒の色：緑＝起点支持、青緑＝起点なし・谷支持、橙＝どちらもなし。未捕捉の起点支持粒は青。実測図は起点支持と谷のみを分ける。谷底線は従来の青領域内の補助表示を維持するが、起点採択には使用しない。

CSV flagsのoutcomeにVALLEYを保存し、起点支持・谷のみ・どちらでもない粒を診断用に分ける。ただし分類Precision・Recall・F1は表示・出力しない。

予測領域との捕捉率・面積率・効率の定義は [state02予測評価](../theme2/valley_onset_state02.md) に集約する。

## 山の起点・稜線

山の起点・稜線は高さ符号を反転して対称に定義する。予測／実測高さの符号を反転し、谷と同じ処理を適用する。局所最高部を山の起点とし、周囲より高い予測領域がそれを捕捉するか評価する。山の捕捉率・面積率・効率と実測稜線被覆率を表示。稜線は各場で独立に抽出し、座標と評価をZIPで保存する。高さ予測や新しい力学は導入しない。独立した丸い頂点には有限長の稜線が存在しない場合がある。

検出の実装は `src/theme2/valley_bottom.py`、谷底線上の局所起点を扱う関数は `src/theme1/valley_origins.py`。起点追跡の表示・出力は [D＋Q追跡](../theme2/dq_origin_history.md) を参照。
