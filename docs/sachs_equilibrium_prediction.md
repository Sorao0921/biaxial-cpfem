# 初期Sachs全テンソルによる3次元平衡予測

## 目的と位置付け

初期方位、初期3次元メッシュ、指定負荷だけから、表面変位を計算する。従来のKベース表面グラフ、今回の平衡予測、state13解析高さを同じ節点IDで比較する。変形中の応力・方位・すべり・ひずみや解析高さは予測の入力にしない。予測APIには解析結果の引数がない。CLIでは両予測を計算・保存した後だけ実測座標を開く。

これは固定された塑性固有ひずみを与える、一方向の小変形弾性平衡モデル。局所応力の再分配は生じるが、その応力を使ってすべり量・方位・加工硬化を更新しない。ひずみ帯の発達を解く増分結晶塑性モデルとは区別する。

## 初期塑性ひずみの定義

初期全粒の体積で重み付けする。Sachs応力は sigma0 diag(1,beta,0)。既存の共通CRSS・共通速度則から各粒の対称テンソル A_i を計算する。局所ごとの規格化はしない。

```
A_i = sum_alpha sign(tau_i_alpha)*abs(tau_i_alpha)^(1/m)*sym(s outer n)
beta: volume_mean(A)_yy / volume_mean(A)_xx = prescribed rho
D = diag(1,rho,-1-rho) / sqrt((2/3)*(1+rho^2+(1+rho)^2))
eps_Sachs_i = prescribed_strain * D_xx * A_i / volume_mean(A)_xx
eps_mean = volume_mean(eps_Sachs)
eps_p_i = eps_mean + eta*(eps_Sachs_i-eps_mean)
```

xx,yy,zz,yz,xz,xyの6独立成分をすべて残す。etaは粒ごとの変形ばらつきの保持率で、既定0.75。1で従来の初期Sachs、0で全粒一様の体積平均塑性ひずみとなる。粒間拘束で一様応力Sachsの過大な変形差が抑えられるという近似であり、力学から導出・同定した係数ではない。体積平均テンソルと各粒の非圧縮性を保ったまま、全成分の平均からの差を同じ率で縮小し、その後に力学平衡を解き直す。z変位の事後補正や実測高さへの振幅合わせは行わない。etaを弱めても小変形近似の問題が解消するとは限らない。体積平均の対角成分が指定した小ひずみに一致し、非対角成分をゼロに置き換えない。非対角の平均成分は側面の拘束により弾性的に抑えられることがある。共通CRSS・共通応力倍率は規格化で相殺するが、粒や系ごとにCRSSが異なる場合はこの扱いでは表現していない。

## 力学平衡

```
eps(u) = sym(grad u)
sigma = C : (eps(u) - eps_p)
div sigma = 0
K u = integral B.T C eps_p dV
```

全初期3次元メッシュを使用し、間引きや表面だけへの縮約はしない。C3D8相当の8節点六面体、2x2x2 Gauss完全積分。B行列のせん断は工学せん断（2eps_yz等）、応力は通常のせん断応力。縮約積分のアワーグラスモードを入れない。並進のみ異なる同形状要素は丸め誤差精度で要素行列を共有する。

弾性は均質等方、既定 nu=0.3、E=69000（初期材料キーワードの値）。外力ゼロ・変位拘束・規定固有ひずみでは共通Eは解から相殺するため、数値行列はE=1で作成する。Eの数値を変えても変位は変わらない。nuは変位に影響する。異方弾性は未実装。

## 境界条件

初期の境界キーワード（x0,x1,y0,y1,z0の拘束）を参考に、初期メッシュの座標面を使って以下を設定する。

- xmin面 ux=0、xmax面 ux=prescribed_strain*Dxx*Lx。
- ymin面 uy=0、ymax面 uy=prescribed_strain*Dyy*Ly。
- zmin下面 uz=0。
- 上面は全方向で変位を固定しない自然な無荷重境界。その他の拘束されていない面の接線方向も自然境界。

元の動的解析の速度履歴を読み込んで再現するものではなく、最終指定ひずみを小変形の変位境界として与える静的近似。反力が生じる拘束自由度と自由節点の力の釣合いを区別する。

## 計算と妥当性の区別

自由自由度に縮約し、代数マルチグリッドで前処理した共役勾配法を使用。既定相対残差1e-8、最大2000反復。収束しなければエラーとして扱い、未収束解を図にしない。

収束は有限変形としての妥当性を保証しない。初期一様応力の速度則では局所すべりが非常に大きくなる粒があり、指定ひずみ0.1でも固有ひずみが1を超えることがある。全変位を初期座標へ加えたときのGauss点Jacobianを確認し、反転要素数と最小Jacobian比を保存する。反転があっても、線形方程式の解を勝手にクリップ・縮小せず、**小変形近似の適用範囲外であることを明示**して表示する。誤差値が良くても、このフラグがある結果を妥当な有限変形予測と判断しない。

- relative_free_force_residual：自由自由度の相対残差。
- free_force_norm_E1：E=1での自由自由度の残差ノルム。
- finite_geometry_valid：変位を有限変形とみなしたときの要素反転がないことのみ。trueでも小変形近似の妥当性を保証しない。
- inverted_deformed_elements：1点以上のGauss点でJacobianが非正となった要素数。
- maximum_eigenstrain_norm：各要素固有ひずみテンソルのFrobeniusノルムの最大値。

## 表示・比較

高さは初期z+uzをそのまま使い、平均板厚のリセット・正規化・振幅合わせをしない。図のxyは指定小変形の面内アフィン座標に投影し、材料点の対応を保つ。解いた実際の3次元変位とdeformed xyzはdisplacements.csvに保存する。負のJacobianを持つ3次元形状を正常なメッシュとして描画するものではない。

従来K予測は対数板厚の指数式、今回のモデルは小変形であり、均一変形でもO(strain^2)の平均高さ差がある。RMSEはこの差も含む。同じ節点の高さ相関、RMSE、両者の高さ標準偏差を表示。3場をプールした節点高さの2〜98百分位を共通色範囲として使う。表示色の飽和は計算値や誤差計算へ戻さない。

## 使い方

UIの「初期指標と表面高さ（state13）」で3次元平衡比較をオンにすると、従来K・3次元平衡・state13高さを横に表示。最初のメッシュ組立は数秒から十数秒程度。初期メッシュとnuが変わらなければ剛性・前処理を再利用する。入力ファイルの更新時はキャッシュを無効化する。

```
python -m tools.theme1.compare_sachs_equilibrium --rho=-0.5 --seed 1 --sd 8
```

この例は5組織を同じ条件で比較する。--texture brassで1組織。--m、--strain、--poisson、--heterogeneityを事前指定できる。既定値はm=0.05、strain=0.1、nu=0.3、eta=0.75。--heterogeneity 1で従来の全ばらつきへ戻せる。K側は既定lambda=1、面内配合0.5、低K抵抗あり。指定条件を解析高さに合わせて自動最適化しない。

出力はdatabase/theme1/sachs_equilibrium_state13/<case>/<config>/。両予測のCSV・条件、全節点変位、初期粒テンソル、比較PNG、評価値、適用範囲フラグを保存する。CLIは指定なしだと全state13ケースを対象とするため、まず条件を絞った確認を推奨。これまで先生向けに作成したKモデル240ケース集は上書きしない。

初期テンソルCSVには調整後のplastic_strain_*と、元のunrelaxed_plastic_strain_*の両方を保存する。etaはmodel.json、CLI精度CSV、設定ハッシュ、UIダウンロード名に反映する。
