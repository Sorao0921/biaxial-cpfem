# 写真上段の図に対応する単純5粒モデル

作成日：2026-11-19。IMG_7006の上段の平面図を基に、中央の菱形を4粒が囲む構成を作成した。全5粒を板厚方向に貫通する柱状粒とし、粒界面の向き・共有面積・隣接位置を明確に比較するための基準モデル。

## 基準形状

- d=0.015 mm。
- 全体：2d×2d×0.5d = 0.030×0.030×0.0075 mm。
- 中央粒1の上面形状：縦・横の対角線がdの正方形を菱形として配置。一辺はd/√2≈0.010607 mm。
- 中央粒の平面重心：(d,d)=(0.015,0.015) mm。
- 中央粒の4頂点：(0.0225,0.015)、(0.015,0.0225)、(0.0075,0.015)、(0.015,0.0075) mm。
- 中央粒は厚さ全体を貫通し、体積重心のzは0.00375 mm。
- 粒2：右上、粒3：左上、粒4：左下、粒5：右下。
- 菱形の各頂点から外周辺の中央へ粒界が伸びる。写真上の図と同じ隣接トポロジー。

寸法は直前の指定を維持し、中央粒の「縦・横対角線」をdとして採用した。dはこのモデルの寸法基準であり、全5粒の等価体積直径を同一にしたという意味ではない。

## 幾何関係

中央粒の側面粒界は板厚に平行な4平面で、上面の粒界線はRDに対して±45°。中央粒は粒2〜5すべてと同じ面積の粒界を共有する。各中央粒界の面積は(d/√2)×(0.5d)≈0.0000795495 mm²。

`grain_interface_summary.csv`に、全ての隣接粒対、粒界法線、法線のXY方位角、共有面積、メッシュ界面数を保存した。法線は粒IDの小さい側から大きい側へ向くように定義。

各粒の配置、粒界法線、共有面積を既知の条件とした上で結晶方位を変更することで、幾何と結晶方位の影響を分けやすい。さらに、同じ4つの隣接方位を右上・左上・左下・右下に置換すれば、隣接する相手の方位と位置関係を比較できる。

## 分割とメッシュ

この形状は、中央点と対角方向の4点を同じzへ置く5母点のVoronoi分割としても定義できる。中央点は(d,d,0.5d)、周囲点のXYは中央から(±d/2,±d/2)。母点とセル重心は別に`grain_geometry.csv`へ記録した。

Voronoiの平面境界に沿って各粒を四辺形ブロックへ分割し、板厚方向へ押し出した。粒IDを立方体要素へ後付けする方法ではなく、粒界に沿う境界適合メッシュである。粒界の階段状近似はない。ブロック内部に見える細い線は要素境界で、追加の結晶粒ではない。

- HEX8要素：27,648。
- 節点：31,977。
- 中央粒：4,608要素、周囲粒：各5,760要素。
- 板厚方向：8分割。
- 全粒界で節点共有。接触・タイ拘束で接続したモデルではない。
- SECTION 1、ELFORM=1を既存設定から継承。PART/MAT ID 1〜5。
- 材料・結晶方位・境界条件・負荷・時間制御は未設定。ソルバー計算は未実施。

## 検証

- 正確に5粒で、中央粒の面共有隣接が2・3・4・5。
- 全体の面接続が1成分。内部未接続面・非多様体面・重複節点・重複要素なし。
- Gauss点8点、要素中心、8頂点のJacobianが正。
- 最小scaled Jacobian≈0.7071、最大辺長比≈3。
- 各粒のメッシュ体積と、正確な平面多角形の面積×板厚が一致。
- `.k`を再読込して接続性・Jacobian・体積を再確認。
- 書出し後の全要素が、5母点による平面Voronoi領域と一致。
- 低密度メッシュで幾何回転0°・15°・30°・45°の生成と接続性・Jacobianも確認。

力学的なメッシュ収束は別途確認する。ELFORM=1を使う解析時は、UMATやhourglass制御等との整合も確認する。

## 再生成と幾何パラメータ

```bash
python -m tools.preprocess.generate_diamond_five_grain_patch \
  --output-dir results/diamond_five_grain_20261119/baseline \
  --d 0.015 --subdivisions 12 --layers 8
```

- `--central-diagonal`：中央粒の対角線長をmmで指定。省略時はd。
- `--rotation-deg`：基準の菱形配置からの幾何回転角。結晶方位のEuler角とは別パラメータ。
- `--subdivisions`：各四辺形ブロックの辺の分割数。
- `--layers`：板厚方向の分割数。

中央粒サイズや幾何回転を変えると周囲粒の形・共有面積も変化するため、出力される粒界の数値を各ケースで使う。

ZIP内の2つのPythonファイルを同じフォルダに置けば、`python generate_diamond_five_grain_patch.py --output-dir baseline`でも生成できる。numpy・matplotlibが必要。
