# 初期指標と隣接粒の結合による表面高さの再構成

## 位置付け

初期方位・初期メッシュ・事前指定の負荷と係数だけから、state13で比較する高さを計算する仮説モデル。変形中の応力・すべり・方位・GOS・実測高さは予測へ入力しない。state13高さは予測完了後に領域と節点IDを対応させて評価する。

手書き整理での正負はχ–K間の相関であって、高さとの相関ではない。組織ごとの目視整合性の違いは、指標や相互作用を比較する動機として扱う。それを使って組織ごとの指標・符号・重みを自動選択する処理は入れない。

これは結晶塑性の力学平衡・三次元変位適合を解いたモデルではない。Taylor指標を使う場合も、Taylorの一様ひずみ拘束から高さを直接導くのではなく、その指標を局所変形候補に読み替える追加仮説である。

## 使う指標

UIで次を切り替えられる。

- K：既定。初期Sachs型モデルの、共通規格化による正味ND収縮傾向。
- χ：粒自身で規格化したND方向性。
- P−：初期Taylor分配の圧縮側寄与。
- P_abs：初期Taylor分配のND活動絶対量。
- M：低Mほど収縮するという追加仮説。計算では−Mを収縮側の信号にする。
- 組合せ：非負の重みを事前に指定。既定はKとP−が各0.5で、他は0。理論的に最適化した重みではない。

χとKは独立ではなく、逆相関なら混合で相殺することもある。初期でのχ–K相関の符号だけから、どちらが高さをよく説明するかは選べない。実測に合うモデルを後から選ぶ作業と、事前指定予測を区別する。

## 初期信号

全初期表面粒について面積重み `a_i=A_i/sum A` を計算する。表示crop外の表面粒も含める。

選択指標 `X_i` を初期面積平均から中心化する。M以外は高値を収縮側、Mは低値を収縮側とする。単独指標は既定で元の差を使う。組合せ時は既定で各指標を初期面積加重RMSで標準化し、異なる尺度の指標を加算する。

```
x_fi = X_fi - sum_i a_i X_fi          # Mについては X=-M
# standardize=True の場合だけ：x_fi /= sqrt(sum_i a_i*x_fi^2)
c_i = sum_f b_f*x_fi,  b_f >= 0, sum b_f = 1
u_i = -eps*c_i  # 旧local方式のみ。現行は下の近傍超過駆動を使う
```

初期で一定の信号は標準化時にゼロとし、入力RMSとflatフラグを保存する。標準化は実測RMSや実測高さを使わない。ただし標準化後のcは物理的な塑性ひずみ速度ではなく、比較用の合成信号であり、振幅の解釈には追加仮定を含む。

画面の2〜98百分位は表示だけの設定であり、cの計算値を切り捨てたり外れ値を除外したりしない。

## 現行の谷形成仮説（v2）

単純な近傍平均でなく、駆動源と沈み込みの伝達を分離する。幾何重みwによる近傍次数をd_i=sum_j w_ijとする。

```
ND_i = sum_j w_ij*max(c_i-c_j,0)/d_i
RD_i = sum_j w_ij*(dx_ij/distance_ij)^2
       *max(K_RD_i-K_RD_j,0)*1[K_RD_i>0]/d_i
TD_i = sum_j w_ij*(dy_ij/distance_ij)^2
       *max(K_TD_i-K_TD_j,0)*1[K_TD_i>0]/d_i
u_i = -eps*((1-alpha)*ND_i + alpha*(RD_i+TD_i))
```

孤立粒は駆動ゼロ。K_RD=Axx/eq(mean A)、K_TD=Ayy/eq(mean A)で正値は伸長。非圧縮条件からK_RD+K_TD=K_NDなので、独立したひずみとして加算せず、近傍方向を考慮した代替仮説と配合する。alpha既定0.5は事前指定値であり、最適化値ではない。標準化を有効にするとND信号cと未標準化の面内Kの尺度は異なるため、alphaの解釈も変わる。

### 低K粒の引き込まれにくさ

変形前の生K値から、全初期表面粒について以下を計算する。表示範囲・実測高さは参照しない。

```
Kref = sum_i a_i*max(K_i,0)
s_i = min(1,max(K_i,0)/Kref)
g_ij = 2*s_i*s_j/(s_i+s_j)
w_drag_ij = w_ij*g_ij
```

Kref=0ならs=0、分母ゼロのgもゼロ。Kが初期の正K面積平均に比べ小さいほど伝達を弱め、K<=0では遮断する。これはKを実剛性とみなす式ではなく、追加の検証仮説。相反的な結合なので、低K粒を引き込む作用と低K粒による引き留め作用の両方が弱まる。gを掛けた後は重みを再規格化しない。**谷の駆動源は元のwを使用**し、抵抗の切替で駆動源を変更しない。UIのチェック／CLIの`--no-low-k-resistance`で比較できる。

`pre_reference_log_response`は平均基準を戻す前の解、`drag_log_change`はその解とuの差。自粒の駆動ゼロでも前者が負になれば引き込みが生じている。最終高さでは指定平均板厚へ戻すので、この中間値と最終的な山谷の符号は区別する。粒表にs、Kref、各駆動成分、辺表にgとw_dragを保存する。

## 隣接粒との結合

初期表面メッシュで線分を共有する粒を隣接とし、点接触は含めない。初期表面粒の面積重心間距離をd、共有粒界長をLとする。

```
w_raw_ij = L_ij / d_ij
w_ij = w_raw_ij / sum_edges w_raw
E(y) = sum_i a_i*(y_i-u_i)^2 + lambda*sum_edges w_drag_ij*(y_i-y_j)^2
```

yは対数板厚の偏差候補。`(diag(a)+lambda*L_graph)y=diag(a)u` を全粒について同時に解く。

第1項は自粒の初期信号を保つ条件、第2項は粒間の高さ変化差を緩和する条件。周囲平均との差をそのまま高さとする処理ではない。自粒の信号が同じでも、隣接する粒や粒界長が異なれば解は変わる。関係式は、

```
a_i*(y_i-u_i) + lambda*sum_j w_drag_ij*(y_i-y_j) = 0
```

であり、隣接粒を介して周囲の応答が伝わる。lambda=0は沈み込み伝達なし（駆動源の近傍差は残る）、既定lambda=1。lambdaは事前指定の仮説係数で、実測へ最適化しない。重みを全エッジで同じ倍率にしても結果は変わらない。

初期cの近傍平均・近傍差・結合による補正も保存するが、これらだけを予測マップとして表示しない。

## 高さへ変換

初期板厚H0、指定相当対数ひずみeps、指定ひずみ比rhoから、非圧縮比例変形の平均板厚を定める。

```
D = diag(1, rho, -1-rho) / sqrt((2/3)*(1+rho^2+(1+rho)^2))
Hmacro = H0*exp(eps*Dzz)
H_i = Hmacro*exp(y_i) / sum_j a_j*exp(y_j)
z_i = initial_bottom_z + H_i
```

指数計算は共通最大値を差し引いて安定化する。高さを負の板厚にせず、初期面積平均の板厚をHmacroへ保つための追加仮定。過度に大きい応答はエラーにする。実測の平均・振幅へ合わせる処理ではない。既定eps=0.1は結果から読み取らないため、負荷計画に合わせて指定する。

粒高さは共有上面節点へ初期要素面積で平均する。xyは指定eps・rhoによるアフィン変形で、実測xyは使わない。粒内変形を独立に解いたわけではない。下面は平坦な初期位置に置く仮定で、下面自体の凹凸や板厚内部の粒間適合は扱わない。

SachsのKは初期全粒の体積平均で規格化するが、今回の結合グラフは表面粒だけである。初期Sachsから得る平均ひずみ比と比較ケースのrhoも保存・表示する。UIでは初期全粒の体積平均D_TD/D_RDが指定rhoに一致するβを自動逆算する。mや初期方位が変わると再計算する。変形履歴や実測高さは使わない。これは平均の面内ひずみ比の一致であり、局所ひずみや全せん断成分の一致を保証しない。CLIも既定は自動で、--betaを明示した場合だけ手動指定。正のRD伸長で一致解がない場合はエラー表示し、未一致値を黙って使わない。

## UI

従来の「初期指標と表面高さ（state13）」内に追加。

- 上部：比較ケース、m、予測に使う指標。βは自動計算値を表示。
- 固定条件の折りたたみ：指定eps、lambda、面内配合alpha、低K抵抗の切替、初期RMS標準化、組合せ重み。
- 主表示：予測表面高さとstate13実測高さの2枚。
- 両図は同じ節点ID・範囲で、両場をプールした高さの2〜98百分位を共通色範囲にする。表示範囲の計算は予測後で、予測値へ戻さない。
- 高さは元のz値。正規化や実測振幅への調整はしない。相関とRMSEは同じ節点IDの値で計算し、空間独立性を仮定するp値は出さない。
- 予測CSV・指標・エッジ・固定条件・比較値をZIP保存できる。
- 初期5指標と実測高さの従来の2段マップは別の折りたたみに残す。初期指標の描画はstate1。

## 再現実行

```sh
# K、単軸応力β=0、m=0.05、結合lambda=1の例
.venv/bin/python -m tools.theme1.predict_neighbor_height --rho -0.5 --seed 1 --sd 8
# 隣接結合なしの比較。先に決めた別仮説として保存する
.venv/bin/python -m tools.theme1.predict_neighbor_height --rho -0.5 --seed 1 --sd 8 --coupling 0
# 指標単独の切替
.venv/bin/python -m tools.theme1.predict_neighbor_height --rho -0.5 --seed 1 --texture cube --sd 8 --source pminus
# 初期指標の標準化を用いた事前固定ブレンド
.venv/bin/python -m tools.theme1.predict_neighbor_height --rho -0.5 --seed 1 --texture cube --sd 8 --source blend
```

出力先は `database/theme1/neighbor_height_state13/{case}/{config_id}/`。条件ごとに別ディレクトリを作り、異なる仮説を上書きしない。初期ファイル版（mtime）、パス、設定をmodel.jsonに記録する。

- `initial_properties.csv`: 全初期粒の指標・体積。
- `grains.csv`: 全初期表面粒の信号、近傍差、候補と補正、予測高さ。
- `edges.csv`: 初期粒界長・距離・重み、初期信号差、予測高さ差。
- `components.csv`: 初期平均・RMS、規格化した組合せ重み。
- `coordinates.csv`: 全面の予測座標。
- `model.json`: 観測値を使わず決めた条件。

**上記を保存した後でのみ実測高さを読む**。続いて評価用crop、比較CSV、evaluation.jsonを保存する。ルートのevaluation.csvは仮説ごとの結果を保持する。実測に合う仮説だけを残す処理はしない。
