# 初期組織だけから表面高さを計算する教師なし仮説モデル

## 検証の範囲

初期結晶方位、初期メッシュ、指定ひずみ比・相当ひずみから予測高さを計算する。変形後の方位・活動・GOS・高さは予測計算に入力しない。シミュレーション高さは予測を保存した後、領域を揃えて誤差を評価するためだけに読む。学習・係数合わせ・予測の振幅合わせは行わない。

Taylor モデルだけから高さが一意に決まるわけではない。本実装は凹凸と粒間勾配を結ぶ追加仮定を明示した、反証可能な閉じ方であり、力学平衡・内部拘束を解く結晶塑性モデルではない。

## 凹凸候補と斜面候補

初期方位と公称 rho で Taylor 最適解を求め、全最適基本解の面外活動 Az の最小・最大の中点を固定して用いる。初期全面の粒を使い、端部除去外の隣接粒も含む。

凹凸候補：

`u_g = -H0 * eps * az_scale * (Az_g - 初期面積加重平均Az)`

高活動ほど谷という仮説。板厚 H0 と指定ひずみ eps を長さ尺度にすることは追加仮定であり、すべり方向だけから厚さ変化を厳密に導いたものではない。

粒界での好ましい勾配と高さ差（初期粒重心間距離を l_ij とする）：

`s_ij = eps * slope_scale * (M_i - M_j) / 初期面積加重平均M`

`d_ij = l_ij * s_ij`

M差から無次元の勾配を定め、距離を掛けて長さ次元の高さ差に変換する。以前の板厚を直接掛ける高さ差指定から見直した。M差の正規化は割合の面外活動ではなく、勾配仮説の尺度設定である。

既定は M の高い側を高所側とする。M 差が大きいところに斜面が生じるという観察だけでは斜面の向きは決まらないため、この向きは未検証の追加仮定である。`--slope-scale -1` による逆方向や `--slope-scale 0` による除去は別モデルとして事前に指定できる。ケースごとの結果に合わせて符号を選択しない。

## 周囲の差を入力した全体高さの計算

次の二次エネルギーを最小化し、全粒の高さ偏差 h を同時に求める。

`E = sum a_g [(h_g-u_g)/H0]^2 + coupling * sum w_ij [(h_i-h_j)/l_ij-s_ij]^2`

両項は無次元。w は勾配条件の結合重みであり、高さへの変換係数ではない。高さ変数の線形系では、勾配の距離除算によって `coupling*w_ij*H0^2/l_ij^2` がエッジ係数になる。共有粒界長／粒間距離の重みと、この勾配の距離除算を区別する。

- a は初期表面積を全面の合計で正規化した重み。
- w は共有粒界長／初期粒重心間距離を、全エッジの合計で正規化した重み。
- 点だけの接触は隣接としない。
- az_scale、slope_scale、coupling の既定は1。理論的に同定された定数ではなく、初期の比較用設定である。

距離ごとに設定した勾配から得る高さ差は、閉じた粒の経路で総和ゼロになるとは限らない。したがって単純な経路積分ではなく、全粒の高さを同時に解くことで不整合を重み付きで分配する。

この最小化は、シミュレーション教師に対する損失の学習ではない。初期情報で定めた局所候補と粒間候補を整合させる線形方程式の解である。周囲との差をそのまま高さとする実装とは異なり、自身の面外活動と隣接 M 差を組み合わせる。

## 絶対高さと連続表面

マクロの平均厚さは、非圧縮・比例対数ひずみ経路を仮定して、正規化した D=diag(1,rho,-1-rho) から `Hmacro=H0*exp(Dzz*eps)` とする。上面高さは `初期下面高さ + Hmacro + h_g`。

共有節点で粒高さを初期要素面積で平均し、節点高さ場を作る。xy は同じ指定ひずみによるアフィン変形。これは連続表示のための補間であり、粒内変形や微細な山・谷を独立に解いていない。下面が粒ごとに動く効果、弾性変形、三次元内部の隣接拘束、境界力学、変形中の方位更新はモデル化していない。


## 出力と評価

保存先：`database/theme1/initial_height_state13/`

- `initial_grain_height.csv`：初期入力、凹凸候補、結合後の予測高さ。
- `initial_edge_slopes.csv`：幾何学重みと候補粒間高さ差。
- `predicted_coordinates.csv`：実測を読む前に計算した全面の予測座標。
- `model.json`：指定条件・固定係数・仮定・学習なしの記録。
- `evaluation_predicted_coordinates.csv`：評価時のみ実測領域に切り出した予測座標。
- `height_comparison.csv`：同じ領域・同じ粒集計での実測と予測。
- `evaluation.csv`：高さ偏差RMSE、元の絶対高さRMSE、Pearson、Spearman、粒間勾配RMSE、正規化節点高さRMSE・Pearson、各場の節点RMS。

予測と実測それぞれに同じ方法で基準面を除き、粒平均高さ偏差を比較する。RMSE は初期面積加重。相関は1粒1サンプルで計算し、空間的独立性を仮定したp値は出さない。粒間勾配は初期重心間距離に対する粒平均高さ差であり、節点局所の微分とは区別する。

UI はAz・P+・P−による3予測と実際の表面高さの4枚を正規化して比較する。各場に対して同じ評価節点上で最小二乗基準面を除き、残差を中心化し、それぞれ自身の節点RMSで割る：

`h_norm = (z - fitted_plane - mean_residual) / RMS(residual)`

予測側に実測RMSを掛けることはしない。元の予測座標・振幅は保存したまま、表示と形状評価だけを正規化する。全4図に共通の対称色範囲（全場の最大絶対値）を用い、赤が山、青が谷となる。粒界線と表面メッシュに沿うコンター形式を保つ。正規化高さRMSEとPearsonを、同じ節点IDを対応させて表示する。節点等重みの形状比較であり、粒集計の従来指標とは区別する。RMS=0の平坦な場はゼロ表示し、相関を未定義として通知する。

正規化されたRMSEは振幅の一致を評価しない。両場が非平坦なら `RMSE_norm^2 = 2(1-Pearson)` であり、この2指標は独立な証拠ではない。振幅・絶対高さの既存誤差もevaluation.csvに保存するが、画面は形状比較に絞る。

仮説の支持・否定は性能で判断する。改善しない場合に結果に合わせて係数を調整すると、本検証の「教師なし」とは別の作業になる。係数感度や符号の比較を行う場合は、事前指定した別仮説の比較として全結果を保持する。

## Az・P+・P−の比較（2026-10-15追加）

実行：

```sh
.venv/bin/python -m tools.theme1.compare_initial_height
# 条件を絞る場合
.venv/bin/python -m tools.theme1.compare_initial_height --rho -0.5 --seed 1 --texture cube --sd 8
```

初期方位のTaylor最適解について、符号付き系すべり量は単位相当ひずみあたりとする。初期試料座標で `c_alpha = gamma_alpha*s_z_alpha*m_z_alpha`、`Pplus=sum(max(c,0))`、`Pminus=sum(max(-c,0))` を計算する。面法線の並びはTaylorソルバーと厳密に合わせ、UMATの系番号を流用しない。全最適基本解で各指標の最小・最大の中点を用いる（最適解集合上では系ごとのすべり符号が固定されるため、この指標は線形となる）。特定の実現すべり解を選んだ値ではなく、範囲の代表値である。

局所候補は `u_Az=-H0*eps*az_scale*(Az-meanAz)`、`u_Pminus=-H0*eps*az_scale*(Pminus-meanPminus)`、`u_Pplus=+H0*eps*az_scale*(Pplus-meanPplus)`。M差の斜面・幾何学重み・全係数・評価範囲は同じにする。P+が大きいほど山、P−が大きいほど谷は追加仮説であり、実測から符号を選ばない。指標間の理論的な尺度差はそのまま保ち、指標自体の標準偏差による再規格化はしない。最終高さだけを各場自身のRMSで正規化する。

**Taylor一様ひずみ拘束の注意**：`Pplus-Pminus=Dzz` が全粒・全最適解で共通。したがって中心化後のP+とP−は同じ分布であり、局所候補は互いに逆符号になる。両者を独立な説明変数とは解釈しない。M差項も加えた最終高さは一般に完全な符号反転ではない。正味P+−P−だけを用いると、初期Taylorモデルでは凹凸情報を得られない。

一括コマンドは全3モデルに共通するケースの比較を `model_comparison.csv` にまとめる。Az出力は従来の保存先、P+は `pplus/`、P−は `pminus/` 以下に同じ構造で保存する。`initial_grain_height.csv` に各P±の最小・最大・中点と `local_activity_relief`、`activity_model` を保存する。P±は単位相当ひずみあたりであり、指定ひずみを局所高さ式で一度だけ掛ける。予測CSVとmodel.jsonを保存してから実測高さを読む。

画面は条件選択、3モデルの正規化RMSE・Pearson表、Az予測・P+予測・P−予測・実測の4コンター（2×2）。全4場で共通の対称色範囲を使う。

## d3plotから必要な値とHV対応

**今回の初期予測に変形後HVは不要**。初期方位CSV、初期メッシュ、指定負荷で計算する。高さの検証にはstate13の節点座標（特にz）と節点IDを使う。節点座標はHVではない。以下は別途「シミュレーションの実測P±」を検証する場合の対応であり、初期予測入力へ混ぜない。

HVはUMAT依存である。表は1始まりのHV番号で、既存LS-PrePost抽出ではfringe番号に1000を加える（例：HV103→fringe1103）。現在の抽出スクリプトはHV103–114、115（すべり）とHV201–203（方位）を指定している。これは旧版0710のHV182–193、179–181とは異なる。実際の解析でリンクしたUMATとNEIPH等の履歴出力設定を照合すること。ソースだけでは解析バイナリの版は確定できない。

## 現在のUI：初期指標と実測高さの直接比較

UIは「初期指標と表面高さ（state13）」へ整理した。初期M・初期Az・初期P−とstate13実測高さの4枚だけを表示し、上記の高さ予測比較・誤差表はUIには表示しない。予測CLI・結果ファイルは保持する。初期方位と指定rhoから指標を直接計算するため、予測ファイルや評価CSVに依存しない。初期指標を同じstate13粒位置に割り当て、元の指標値を個別色範囲で表示する。実測高さは基準面除去・自己RMS正規化する。Az・P−は全最適基本解の範囲中点である。


現在の直接比較UIではAzという名称を外し、`P_abs = sum(abs(gamma_Taylor*s_ND))` と明示する。初期方位とrhoだけから計算した相当ひずみ1のTaylor分配を用いるため、旧UIの「初期Taylor Az」と数値的に同じになる。実測すべりを使うAzパイプラインとは独立である。変形中の方位・すべり履歴は一切入力しない。state13高さ・座標は検証と描画位置にのみ使う。

直接比較UIの実測高さは正規化を外し、基準面除去も行わず元の表面高さzを表示する。色範囲は他の高さメニューと同じHEIGHT_RANGEとする。過去の予測評価CLIの正規化設定は変更しない。

初期3指標の描画座標と表示範囲は、対応するstate1の表面座標CSVを使用するよう変更。state1座標が欠損している場合は明示し、state13へ代替しない。右端の実測高さだけstate13を使用する。
