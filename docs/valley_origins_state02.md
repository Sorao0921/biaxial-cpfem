# state02：谷底線の局所最深部を起点として数える

最新の主評価。一本の連結谷底線につき1点だけではなく、同じ線の中にある複数の局所最深部を残す。初期5条件の予測式、予測の局所低さRMS0.5倍、実測の青色域制限は変更しない。

## 実測の起点

青色域の谷底線を節点・線分のグラフとして扱う。隣接点より低い部分が候補。同じ高さでつながる平坦部はまとめて1候補とし、その中央に近い節点を代表点にする。より深い最小部へ合流するまでの鞍部の高さと、候補の高さの差を顕著さ（prominence）とする。連結領域内で最深の候補は、その線上の最高点までの高さ差を使用する。

既定で顕著さが実測表示高さ範囲（2–98%）の5%を超える候補を残す。線に沿った距離が初期代表粒径の0.5倍未満の候補は深い側へ集約。空間的に近くても線がつながっていなければ集約しない。線の切断端は起点にしない。線全体が平坦など、線に沿う局所最深部を特定できない場合は無理に1点を作らない。これらは予測精度に合わせて選んだ値ではなく、事前指定の検出仮説。

代表点に接続する実際の谷底線分を含む粒だけを起点の支持粒として扱う。粒界上では両側を代替候補とするが、線分が通らず頂点だけ触れる粒は追加しない。起点の座標・高さ・顕著さ・元の平坦部・連結領域ID・支持粒IDを保存する。便宜的な幾何学的「起点」であり、時間的な発生順序を同定するものではない。

## スコアの単位

主指標はorigin_recall＝捕捉した実測起点数／実測起点数。支持粒のいずれかを予測が低いと捉えればその起点を捕捉。同じ起点の両側を予測しても1回だけ数える。同じ谷底線上の離れた最深部は別の起点として数える。起点がない場合は未定義。

粒単位のPrecision・Recall・F1は、起点を含む支持粒への二値判定として補助的に残す。起点捕捉率と粒Precisionの分母は異なるので、この2つを混ぜたF1は作らない。起点だけの予測点集合を定義していない現状では、起点単位のPrecision/F1を主張しない。

因子の追加で新規捕捉・見逃しになった起点IDも保存。全谷底線の被覆率は診断用に残すが、線の長さを主得点にしない。旧評価と新評価の数値をそのまま性能改善として比較しない。

## UIと出力

実測高さ図で谷底線は緑、評価する起点は黄色の星。主表は起点数・捕捉数・起点捕捉率と補助の粒Precision/F1。従来どおり検出／高さを上下配置し、4列で折り返す。

origins.csv：代表座標・高さ・顕著さなど。
origin_nodes.csv：平坦部を構成する節点。
origin_support.csv：起点と支持粒。
origin_flags.csv：モデル・閾値ごとの起点捕捉。
transition_origins.csv：モデル追加による起点ごとの変化。

CLI既定出力はdatabase/theme1/valley_origins_state02_five_models、集計はoutput/reports/valley_origins_state02_five_models。旧集計は上書きしない。箱ひげの既定指標は起点捕捉率、補助の粒Precision・粒F1で、単位差を凡例に明記する。全ケースの新集計は別途実行が必要。
