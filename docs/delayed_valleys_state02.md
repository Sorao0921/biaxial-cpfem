# state02の固定候補と後続の谷形成

「谷形成起点の因子比較（state02）」の補助確認で、後続stateを追跡できる。
5モデルの予測粒と初期Taylor factor差の候補粒界をstate02で固定する。後続CPFEMは検証にだけ使用し、予測集合や閾値を調整しない。

## 何を数えるか

- `unmatched_state02`：state02で実測起点に対応しなかった候補。
- `later_origin`：その候補が後のいずれかの観測stateで起点に対応。移動・再検出も含む。
- `later_novel_origin`：過去の全観測起点から初期の代表粒径の0.5倍を超えて離れた局所起点への対応。
- `later_new_valley_origin`：上記のうち、その谷底線の連結成分全体が過去の谷底線に接していないもの。
- `still_unmatched`：利用可能な後続stateでは対応しなかった候補。将来も形成しないことを意味しない。
- `censored`：後続stateのどこかで候補の評価領域が欠けたもの。未対応数と重複しうる。

粒候補と粒界候補は異なる単位なので別集計する。候補数は起点数ではなく、1候補に複数の起点があっても1件。`captures.csv`は起点単位で各モデル・粒界・和集合の捕捉を記録する。

## 座標と新規性

同じ節点IDを初期材料座標へ戻して比較する。変形による平面内移動を新規形成と誤認しない。
現在の谷底線の連結成分が過去の線に初期格子間隔の1.01倍以内で接する場合は、既存谷の成長・結合側へ分類する。過去のすべての観測stateを履歴に残し、消えて再出現した起点を新規に数えにくくする。

実測抽出は各stateで同じ青色域・曲率・局所低さ・起点顕著度の規則を使う。色域の数値閾値は各state自身の高さ分布から算出する。新規性は検出形状についての分類であり、閾値越え・出力間隔・位置許容幅の影響を受ける。物理的な核生成や因果関係の証明とは区別する。欠落stateはmethod.jsonに記録し、初出stateは厳密な発生時刻ではなく最初に観測できたstateである。

## 出力

画面では候補集計、state別の谷底線・起点数、state03以降の全状態の高さと起点（1行4枚）、候補ごとの初出stateを確認できる。ZIP内の`delayed/`にCSVと規則を保存する。

個別ケースを再計算する例：

```sh
.venv/bin/python -m tools.theme1.validate_delayed_valleys --rho -0.5 --seed 1 --texture brass --sd 2
```

出力は`output/reports/delayed_valleys/`以下。`candidates.csv`は候補ごとの初出state、`observations.csv`は毎stateの対応・可視性、`origins.csv`は起点の出現分類と履歴距離、`lines.csv`は谷底線の新規連結成分、`states.csv`はstate集計を記録する。
