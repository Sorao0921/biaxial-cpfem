# UMAT履歴出力とHV番号の対応

## 抽出・検証の前提

**今回の初期予測に変形後HVは不要**。初期方位CSV、初期メッシュ、指定負荷で計算する。高さの検証にはstate13の節点座標（特にz）と節点IDを使う。節点座標はHVではない。以下は別途「シミュレーションの実測P±」を検証する場合の対応であり、初期予測入力へ混ぜない。

HVはUMAT依存である。表は1始まりのHV番号で、既存LS-PrePost抽出ではfringe番号に1000を加える（例：HV103→fringe1103）。現在の抽出スクリプトはHV103–114、115（すべり）とHV201–203（方位）を指定している。これは旧版0710のHV182–193、179–181とは異なる。実際の解析でリンクしたUMATとNEIPH等の履歴出力設定を照合すること。ソースだけでは解析バイナリの版は確定できない。

### 現行抽出に対応する `external/dyn_umats_from_c/dyn21umats_fcc_dsl.f`

|量|HV（α=1…12）|用途・制約|
|---|---|---|
|各系累積絶対すべり Γα|102+α = 103…114|Azの区間活動。符号は復元できない|
|総累積絶対すべり|115|総活動確認|
|系方向 s_z|33+3(α−1) = 33,36,…,66|保存されるs11のz成分|
|系面法線 m_z|69+3(α−1) = 69,72,…,102|保存されるm11のz成分|
|Bunge方位（radian）|201,202,203|方位確認・初期方位をd3plotから取得する場合は初期stateのみ|
|符号付き系すべり速度 γdotα|**既存HVに保存なし**|P±には追加出力が必要|

構成則では `ss_vec_to_configuration(fe,...)` 後のs11e,m11eからSchmidテンソルを作る。保存されるs11,m11と、構成則で用いた実配置のテンソルを同一視しない。厳密なND塑性ひずみ寄与の検証には、実際の座標系に整合するSchmid zz成分または系別ND寄与をUMATから直接出力するのが確実である。別のcp_ph/cp_hama版には別オフセットがあり、この表を適用しない。

### 旧版 `external/dyn_umats_from_n/dyn21umats_0710.F`

|量|HV（α=1…12）|
|---|---|
|符号付き系すべり**速度** γdotα|164+α = 165…176|
|Schmid zz成分（出力時刻側）|55+6(α−1) = 55,61,…,121|
|系方向 s_z（出力時刻側）|196+3(α−1) = 196,199,…,229|
|系面法線 m_z（出力時刻側）|232+3(α−1) = 232,235,…,265|
|各系累積絶対すべり|181+α = 182…193|
|Bunge方位（radian）|179,180,181|

根拠：同ソースの `hsv(164+l)=dgamma(l)`、`gamma_slip+=abs(dgamma)*dt1`、`hsv(55+k)=Pac_n1(3,3,l)`、`hsv(196+k)=s1_n1(3,l)`、`hsv(232+k)=m1_n1(3,l)`。

HV165–176は増分ではなく速度。時間積分 `∫ max(±γdotα(t)*Szzα(t),0) dt` が必要で、state13の瞬間値×全時間では再構成できない。粗い出力stateでは途中の符号反転・方位変化を落とす。厳密な区間積算が必要なら、各内部時間ステップでP±を積算し専用HVとして出力する。既存HVの空き番号は解析版と出力設定を確認して確保する。複数積分点は同一の点を対応させ、正負分離前に要素平均しない。
